## 6. 附：数据口径提醒

- 表内为**官方挂牌价**，第三方托管端点价不等于官方降价，转售加价也不等于官方涨价。
- 聚合路由首页价 = 最低端点价（常是缓存读价或不参与标准路由的端点），不能当通用价横向比。
- 赠额 / 限免 / 积分**不算长期价格**：清零不结转，客户端内额度 ≠ 可导出 API Key，各家积分 / Credits / 墨点不可横向比。
- 订阅制、积分制折扣若核不到同口径端点报价，只写进活动部分，不进取价表。
