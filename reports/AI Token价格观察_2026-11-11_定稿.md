## 口径纪律（每期照此执行）

1. 赠额会清零、不结转，**不写进长期成本表**；
2. 客户端内额度 ≠ 可导出 API Key，别拿它顶 API 账单；
3. 「7000 万」「2.7 亿」「百亿」多为**多模型加总**或**全场总量**，不是单账号到手量；各家积分 / Credits / 墨点 / Neurons 不可横向比大小；
4. OpenRouter 等第三方托管商的挂牌价波动**不算官方降价**，转售商加价也不算官方涨价；渠道价与官方价分列；
5. 领取页默认勾选自动续费要手动取消；Token 套餐普遍不支持 7 天无理由退换；
6. 二手「超低价 Token / 中转站」风险极高，采购走官方渠道。
